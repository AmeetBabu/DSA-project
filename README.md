# Movie Ticket Booking System

A Python Tkinter GUI project that demonstrates lists, linear and binary search, singly linked lists, queues, stacks, and recursion.

## Run

```powershell
python main.py
```

Tkinter is included with standard Python installations on Windows.

## Features

- View, add, and update movies
- Search movies by name using linear search
- Search movies by ID using binary search
- Store bookings in a singly linked list
- Manage unavailable-ticket customers in a FIFO queue
- View and process the most recent waiting customer
- Track recent bookings in a LIFO stack
- Count movies recursively
